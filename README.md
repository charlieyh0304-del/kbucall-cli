# kbucall

복지콜 예약을 터미널에서 합니다.

화면을 보지 않고 쓰도록 만들었습니다. 출력은 평문 한 줄씩이고 색, 스피너, 박스 문자를
쓰지 않습니다. 표로 정보를 전달하지 않습니다 — 읽는 순서 그대로가 의미입니다.

## 설치

```
npm install -g charlieyh0304-del/kbucall-cli
```

npm 레지스트리에는 올리지 않았습니다. 위 명령이 깃허브에서 바로 받아 설치합니다.

Node 18 이상이 필요합니다. 의존성은 없습니다.

`kbucall` 또는 짧게 `kbu` 로 실행합니다.

받아서 직접 돌려도 됩니다.

```
git clone https://github.com/charlieyh0304-del/kbucall-cli.git
node kbucall-cli/bin/kbucall.js help
```

## 쓰기

```
kbucall login
kbucall book "둔촌동 1376-1" "여의도동 2" --at +10m
kbucall list
kbucall cancel
```

`kbucall help` 로 전체 사용법을 볼 수 있습니다.

### 로그인

복지콜 앱에 쓰는 이름, 전화번호, 비밀번호를 입력합니다. 가입 절차는 따로 없습니다.

비밀번호는 저장하지 않습니다. 한 번 보내고 버립니다. 남는 것은 90일짜리 토큰이고
`~/.config/kbucall/config.json`(Windows는 `%APPDATA%\kbucall\config.json`)에 저장됩니다.

### 접수

```
kbucall book "둔촌동 1376-1" "여의도동 2" --at +10m
```

`--at` 은 `+10m`, `14:30`, `2026-09-24T14:30` 형식을 받습니다. 생략하면 5분 뒤입니다.
5분 이내면 바로 접수하고 결과가 나올 때까지 기다립니다.

**주소는 지번으로 넣으면 가장 잘 찾습니다.** 복지콜 접수가 지번 기준입니다.
건물명이나 도로명도 되지만 후보를 고르는 단계가 한 번 더 생깁니다.

접수 전에 확인을 받습니다. 붙일 수 있는 옵션이 둘 있습니다.

- `--dry-run` 주소 확인까지만 하고 접수하지 않습니다. 처음 써볼 때 쓰세요.
- `--yes` 마지막 확인을 건너뜁니다.

`--yes` 로도 건너뛸 수 없는 것이 하나 있습니다. **주소 후보가 여러 개일 때는 반드시
사람이 골라야 합니다.** 같은 동 이름이 여러 지역에 있어서, 임의로 고르면 다른 지역으로
차가 갑니다. 고를 수 없는 환경이면 접수하지 않고 멈춥니다.

번지가 확인되지 않는 주소도 접수하지 않습니다. 번지 없이 접수되면 복지콜 콜센터가
전화해서 위치를 다시 확인하게 됩니다.

### 취소

```
kbucall cancel
```

접수된 차량을 취소합니다. 아직 접수 전인 예약은 취소가 아니라 삭제입니다.

```
kbucall list
kbucall rm <예약번호>
```

복지콜에는 배차 후 취소와 하차 후 재접수에 대기 규정이 있습니다. 취소가 거부되면
그 이유가 나옵니다.

## 스크립트에서 쓰기

```
export KBUCALL_TOKEN=...
kbucall book "출발지" "도착지" --at +10m --yes
```

`KBUCALL_TOKEN` 이 있으면 저장된 토큰 대신 그 값을 씁니다.

터미널에 직접 입력할 수 없는 환경이라면 로그인도 환경변수로 됩니다. 셋이 다 있으면
묻지 않고 바로 로그인합니다.

```
KBUCALL_NAME=... KBUCALL_PHONE=... KBUCALL_PASSWORD=... kbucall login
```

이렇게 쓰면 비밀번호가 셸 기록에 남습니다. 파일에서 읽어 넣거나, 쓰고 나서 기록을
지우세요. 가능하면 그냥 `kbucall login` 으로 직접 입력하는 쪽이 낫습니다.

파이프로 실행하거나 에이전트가 호출한 경우처럼 사람의 답을 받을 수 없으면, 확인이 필요한
지점에서 접수하지 않고 멈춥니다. 후보 목록은 출력되므로 그것을 사용자에게 보여주고
고른 주소로 다시 부르면 됩니다.

## 이용 자격

복지콜은 지역 기반 서비스이고 등록된 이용 자격이 있어야 접수됩니다. 자격이 없으면
로그인 단계에서 막힙니다.

## 만들어 쓰기
